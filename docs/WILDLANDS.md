# Wildlands — перевірений шлях читання

19.10.2026 перевірено локальну Steam-копію з `/path/to/SteamLibrary/steamapps/common/Wildlands/`. Читання не змінює файли гри.

- Первинна інвентаризація: 19 `.forge`, включно з DLC. Індекс десяти кореневих архівів перевірено обмеженим незалежним читачем; версія 27, заголовок 1050 байтів, записи індексу 20/192 байти.
- Досліджено пакети локалізації з `DataPC.forge` і `DataPC_patch_01.forge` (тип `0x6e3c9c6f`). Англійські пакети: UI, Subtitles, порожній EManual. За однаковими package ID патч має пріоритет.
- Контейнер CFD має версію 1, алгоритм 1 (LZO1X), розміри блоків у 16-бітових полях; контрольні суми adler32 із seed 0. Це відрізняється від контейнера Breakpoint v3 / Oodle / 32-бітових розмірів.
- Штатна безпечна декомпресія `lzo1x_decompress_safe`; блоки з однаковими raw/stored розмірами збережені без стиснення. Межі ресурсів, довжини, контрольні суми й фактичний результат перевіряються.
- Непорожні LocalizationPackage використовують ту саму перевірену рамку й Re-Pair-граматику, що й досліджені пакети Breakpoint. Порожній EManual із category 2 дозволено лише в читачі Wildlands, не в Breakpoint.
- Результат: **19 034 UI + 17 087 Subtitles = 36 121 рядок**; EManual порожній. Кожний текст і ID зіставлено з незалежним Python-декодером на окремо розпакованих ресурсах. Префікс ID `grw:`, профіль `wildlands`; це відокремлено від `grb:`.

## Використання

Найпростіше — **Проєкт → Витягнути тексти Wildlands…** в редакторі. CLI для нового вихідного файла:

```sh
./bin/anvil-extract-wildlands \
  --game-dir "/path/to/SteamLibrary/steamapps/common/Wildlands" \
  --output "/ваша/робоча/папка/Wildlands-UA.als.json"
```

Каталог результату має існувати й бути поза грою; перезапис наявного файла заборонений. DLL гри й Wine для Wildlands не потрібні. На Arch потрібна системна бібліотека `lzo`; на Windows — відповідна LZO2, наприклад [пакет vcpkg lzo](https://vcpkg.io/en/package/lzo.html). Не виконували Windows-збірку чи її запуск.

`plugins/wildlands` — окремий Qt-плагін для **декодованого** `*.localizationpayload`. Пакети двох ігор мають спільну сигнатуру, тому вона не дозволяє автоматично визначити гру: профіль/плагін потрібно вибирати явно. Нативні плагіни — виконуваний код, не пісочниця.

## Межі

Це не універсальна підтримка `.forge`: перевірено конкретні англійські пакети цієї інсталяції. Витягування з DLC, інші мови, перепакування, прийняття UMAC рушієм та шрифтові зміни Wildlands не перевірялися. Ігрові архіви до пакета програми не входять.
