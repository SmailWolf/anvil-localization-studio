# Інструкція · Anvil Localization Studio 0.7.0-beta.2

**Це бета-версія.** У комплекті немає перекладів ігор, ігрових текстів, архівів, патчів або самої моделі. Програма читає вашу встановлену гру та зберігає робочі результати окремо.

## 1. Запуск і мова інтерфейсу

**Windows 10/11 x64:** розпакуйте весь Windows ZIP, наприклад у Документи, та відкрийте **Start-Anvil-Studio.cmd** або `bin\anvil-studio.exe`. Qt, LZO та бібліотеки компілятора включені. Встановлювати Qt, MSYS2 або Wine для запуску не потрібно. Деталі — [WINDOWS.md](WINDOWS.md).

**Linux:** попередня Linux-бета доступна в релізах; запуск — `start-studio.sh`, потрібні сумісні системні бібліотеки. Дивіться [BUILD.md](BUILD.md). Не розташовуйте програму чи проєкти всередині папки гри.

У меню **Мова / Language** оберіть **Українська** або **English**. Збережіть відкритий проєкт і перезапустіть програму. Вибір зберігається. Це лише мова інтерфейсу: локальний переклад наразі налаштований з англійської на українську.

## 2. Завантаження моделі

1. Відкрийте **Переклад → Завантажити модель…**. Це можна зробити навіть без відкритого проєкту. Така сама кнопка є у вікні перекладу.
2. Перегляньте умови Gemma за посиланням у вікні. Оберіть папку для моделі поза грою. Стандартна папка — локальні дані Anvil Studio; потрібно щонайменше 2,6 ГБ вільного місця.
3. Натисніть **Завантажити**. Програма завантажить TranslateGemma 4B Q4_K_M з Hugging Face: **2 489 909 760 байтів**. Показуються прогрес і кількість МБ.
4. Дочекайтеся повідомлення про успішну перевірку. Програма звіряє розмір, формат GGUF і SHA-256, після чого запам'ятовує шлях.

**Скасувати завантаження** зупиняє його й прибирає незавершений файл. Після скасування чи помилки наступне завантаження починається спочатку. Наявні моделі не перезаписуються: оберіть іншу папку або вкажіть готовий GGUF кнопкою **Обрати…** у вікні перекладу. Після завантаження інтернет для перекладу не потрібен. Ігрові тексти не надсилаються на Hugging Face.

## 3. Витягування текстів

1. Оберіть Wildlands або Breakpoint у списку ігор.
2. Натисніть **Витягнути з гри…** та оберіть головну папку встановленої гри, де є `DataPC.forge` та виконуваний файл гри. Папки `videos`, `sounddata` або `support` не підходять.
3. Збережіть новий **Anvil Project** (`*.als.json`) у **Документи → Anvil Projects**, поза грою. Це ваш робочий файл, що містить оригінали, переклад, ID та глосарій.
4. Дочекайтеся завершення. У редактор відкриються англійські пакети з основного архіву та патча. Інші мови й усі DLC поки не охоплені.

Для Breakpoint потрібна власна `oo2core_7_win64.dll` з гри; на Linux також Wine та helper із пакета. DLL гри не поширюється. Для Wildlands використовується LZO2. Файли встановленої гри під час витягування не змінюються.

Пункт **Додатково — декодовані ресурси** призначений для вже декодованих файлів. Звичайному користувачу слід починати з **Витягнути з гри…**, а не шукати готовий LocalizationPackage у папках гри.

## 4. Редагування та переклад моделлю

Редагуйте колонку **Український переклад**. **Ctrl+Enter** підтверджує комірку, Enter додає новий рядок. Статуси: **До перекладу**, **Перекладено**, **Перевірено**. Статус «Перевірено» ставте після власної вичитки. Глосарій містить терміни та відповідники.

Для всієї бази натисніть **Перекласти всі неперекладені…**. Ліміту 500 немає; пошуковий фільтр не обмежує цю команду. Для частини бази виділіть рядки через Ctrl/Shift і використайте **Перекласти вибрані рядки…**.

У діалозі перевірте шлях до моделі й рушія `llama-server`. У Windows-пакеті є CPU-рушій. У попередньому Linux-пакеті є CPU і CUDA рушії. Якщо NVIDIA/CUDA недоступна, вимкніть CUDA. CPU перевірений; CUDA цієї версії не пройшла фактичної перевірки. У збірці з вихідних кодів рушій треба надати окремо.

Натисніть **Перекласти**, дочекайтеся результатів, перегляньте їх і натисніть **Застосувати позначені**. До застосування документ не змінюється. Модель завантажується в пам'ять на час роботи та вивантажується після завершення або зупинки.

Точні повтори перекладаються одним запитом, а результат застосовується до відповідних ID; самі записи не видаляються. За замовчуванням уже готові переклади та службові `Name:`, `Context:`, `Acting:`, `//WARNING` пропускаються. Для однакових слів із різним значенням виправляйте окремі записи вручну.

Підстановки й теги перевіряються, але зміст та граматику потрібно вичитувати. Рядки понад 6000 символів не перекладаються. Проміжний кеш дозволяє повторно використати готові результати після зупинки; це окрема функція від завантаження файла моделі.

## 5. Збереження, резервні копії та оновлення гри

Регулярно натискайте **Зберегти JSON…**. JSON зберігає весь проєкт. CSV використовуйте для обміну рядками; глосарій зберігається в JSON. Імпорт CSV замінює рядки поточного проєкту.

Є автокопії раз на хвилину та резервні копії при збереженні. Відновлення — **Проєкт → Відновити автокопію…**. Робіть також власні копії важливих проєктів.

Після оновлення гри відкрийте попередній JSON і оберіть **Оновити проєкт із гри…**. Збережіть результат під новою назвою. Переклади переносяться за ID та незмінним оригіналом; нові й змінені рядки потребують перевірки. Зміна формату архівів після оновлення може вимагати нової версії читача.

## 6. Експериментальне пакування

**Проєкт → Запакувати переклад…**: оберіть оригінальну гру та нову папку результату поза грою. Можна пакувати лише перевірені рядки. За прапорцем створюються повні змінені копії `.forge`, що можуть займати багато ГБ; без прапорця — компактні дані для подальшого складання.

Програма перевіряє структуру та повторно читає тексти з результату. **Це ще не підтверджений робочий мод:** запуск нових пакетів у грі не перевірено, UMAC не перераховується, шрифт для українських літер не додається. Автоматичного встановлення немає. Пакет із позначкою `INCOMPLETE` використовувати не можна. Деталі — [PACKAGING.md](PACKAGING.md).

## Якщо виникла помилка

- **Немає моделі:** завантажте її через меню або оберіть готовий GGUF.
- **Завантаження зірвалося / не збіглася сума:** перевірте інтернет і місце; повторіть. Незавершений файл не стає моделлю.
- **Файл уже існує:** оберіть його у вікні перекладу або іншу папку завантаження.
- **Не знайдено рушій:** розпакуйте весь Linux-пакет; для source-збірки вкажіть сумісний `llama-server`.
- **Output / Wine prefix must be outside game directory:** збережіть проєкт і робочі файли у Документах, поза грою.
- **Квадрати замість українських літер у грі:** переклад тексту не додає підтримку літер до ігрового шрифту; автоматичне виправлення шрифтів у цій бета-версії відсутнє.

Для повідомлення про помилку вкажіть версію програми, ОС, гру, дію та текст помилки. Не додавайте ігрові архіви, DLL, повні витягнуті бази або особисті дані до публічних Issues.
