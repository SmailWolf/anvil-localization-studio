# Пакування перекладу · 0.6

Редактор може зібрати переклади з відкритого проєкту в нативні LocalizationPackage та повні змінені **копії** архівів Wildlands або Breakpoint. Результат створюється в новій папці поза грою; установлені файли не змінюються.

**Статус — експериментальний.** Перевірено структуру, ID, контрольні суми та повторне декодування. Запуск цих нових довільних пакетів у грі ще не перевірено. UMAC не перераховується; кириличні гліфи шрифтів не додаються. Це не універсальний перевірений інсталятор Anvil-модів.

## Через редактор

1. Відкрийте свій `*.als.json`, додайте/прийміть переклади. Завершіть активну комірку Ctrl+Enter.
2. Натисніть **«Запакувати переклад…»** на панелі або через **Проєкт**.
3. Вкажіть папку тієї самої гри, з якої отримано оригінальні рядки проєкту.
4. Виберіть **нову** папку пакета поза грою, наприклад `Документи/Anvil Projects/breakpoint-UA-package`.
5. За замовчуванням створюються повні копії `.forge` в `archives/`. Потрібне вільне місце за повним розміром змінених вихідних архівів — це можуть бути багато ГБ. Програма не зменшує архів гри до самих перекладених текстів: решту ресурсів вона зберігає. Якщо зняти прапорець повних копій, залишиться лише компактний пакет для подальшого складання.
6. Прапорець **«Лише перевірені»** включає тільки `reviewed`. Без нього включаються `translated` і `reviewed`; `todo` й порожні переклади не пакуються. Інші тексти залишаються оригінальними. Ідентичний оригіналу переклад не створює змін.
7. Натисніть **«Запакувати»**. Читання й хешування великих архівів може тривати кілька хвилин; у вікні показано поточний архів та обсяг. Кнопка зупинки перериває роботу без змін установленої гри.

Пакується поточний стан відкритого документа, включно з підтвердженими, але ще не збереженими в JSON правками. Сам JSON-проєкт теж збережіть Ctrl+S для продовження роботи.

## Що буде в папці

- `manifest.json`: гра, кількість змін, package ID, контрольні суми вихідних і нових архівів, явні позначки невиконаних ігрових/шрифтових перевірок.
- `DataPC*.forge.anvildelta`: компактні різниці, прив’язані до повного SHA-256 оригіналу. Самі по собі грою не читаються.
- `archives/DataPC*.forge`: повні змінені копії відповідних архівів, якщо вибрано їх створення. Імена відповідають вихідним архівам; довільний новий patch-02 не вигадується.
- `ПРОЧИТАЙТЕ.txt` і `archives/EXPERIMENTAL.txt`: статус і межі використання.
- `INCOMPLETE.txt` під час роботи. Якщо він залишився після зупинки/помилки, відповідний результат ще не завершений.

До пакета потрапляють лише змінені архіви; утиліта не копіює всю інсталяцію. Архіви містять і вихідні ресурси гри, потрібні для повної копії, тому вони не включені в ZIP самої програми.

## Перевірка актуальності

Для кожного перекладеного ID програма читає актуальний ресурс із `DataPC.forge` / `DataPC_patch_01.forge`; патч має пріоритет за однаковим package ID. ID і оригінальний текст повинні збігатися з проєктом. За розбіжності пакування зупиняється з вказівкою рядка — спочатку виконайте **Оновити проєкт із гри…** або використайте правильну вихідну версію гри.

Не змішуйте проєкти та архіви двох ігор. Власні рядки з довільними ID не можуть автоматично додаватися до ігрового пакета. Перевіряються поширені підстановки, теги та переноси; зміна їх набору зупиняє експорт. Це не повна перевірка всіх форматувальних кодів Anvil.

## CLI

```sh
./bin/anvil-pack-translation --mode pack \
  --project "/absolute/UA.als.json" \
  --game-dir "/absolute/game" \
  --output-dir "/absolute/new-package"
```

`--delta-only` вимикає копіювання повних архівів; `--reviewed-only` обмежує статус. Для Breakpoint на Linux додайте `--wine-prefix "/absolute/work/wine-prefix"`; потрібні Wine, helper поруч із програмою та ваша `oo2core_7_win64.dll` у папці гри. DLL копіюється в тимчасову папку для читання і не поширюється.

Подальше складання повних копій із компактного пакета:

```sh
./bin/anvil-pack-translation --mode assemble \
  --package-dir "/absolute/new-package" \
  --game-dir "/absolute/original-game" \
  --output-dir "/absolute/new-archive-copies"
```

Потрібні ті самі вихідні архіви: їх повний SHA-256 має збігатися. Нова папка результату не може існувати заздалегідь. Жоден із режимів не встановлює копії у гру.

## Структурна перевірка

Підтримано лише спостережений індекс v27/1050 із записами 20/192 байти. Перевіряються межі, цикли, дублікати ID, перетини й узгоджені довжини. Перебудований текст повторно декодується; усі ID і всі тексти зіставляються з очікуваним результатом, включно з неперекладеними.

Wildlands отримує CFD v1/LZO1X із 16-бітовими розмірами блоків; Breakpoint — CFD v3 із коректно позначеними raw-блоками. Блоки ≤32 КіБ і мають adler32 seed 0. Нові ресурси дописуються до копії з вирівнюванням; оновлюються лише відповідні offset/size у таблиці та metadata size. Старі payload, інші записи, sidecars і невідомі поля зберігаються.

Перед записом обчислюються повні SHA-256 віртуального вихідного й нового архівів. Під час складання перевіряється, що вихідний архів усе ще має цей SHA-256, а потік результату відповідає очікуваному; копія фіксується атомарно через QSaveFile та її індекс читається знову. Пошкоджена різниця або інший оригінал не створять завершеного архіву. У результаті помилки може лишитися папка з INCOMPLETE; файли гри при цьому незмінні.

Межі: JSON проєкту ≤128 МіБ, delta ≤256 МіБ, до 1024 ділянок, архів ≤512 ГіБ. Формат delta `ANVILMOD1`: version u32=1, sourceSize/resultSize u64, по 32 байти binary SHA-256, editCount u32, далі `{offset u64, length u32, bytes}`; little-endian, без перетинів і зайвих байтів. Це окремий формат від фіксованих тестових v2/v3.

## Ігровий тест та шрифт

Успіх пакування підтверджує структуру і відповідність текстів, **не працездатність у рушії**. Копії не встановлюються автоматично. Перед самостійним ігровим тестом потрібні повні резервні копії всіх файлів, які планується замінити, і можливість їх відновити. Не використовуйте незавершені outputs з INCOMPLETE.

Український або білоруський текст може відображатися квадратами без сумісного шрифту. Окремий старий шрифтовий тест v3 стосується лише конкретної версії Breakpoint; це не шрифт Wildlands і не гарантія сумісності з оновленими архівами. Пакування не замінює font-ресурси та не перераховує UMAC — ці межі також записані у manifest.json.
